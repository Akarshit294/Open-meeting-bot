# Research notes

One note per research task, named `T<phase>.<n>-<slug>.md` (for example `T0.1-prior-art.md`).

Each note has five parts:

1. **Question:** what the task set out to learn.
2. **What we did:** the steps, with dates.
3. **What we saw:** the evidence: log lines, numbers, screenshots. No voices or faces of real
   people.
4. **What it means:** the answer, and how sure we are.
5. **Next:** what this changes in `plan.md`.

Meeting platforms change their pages over time. Date every observation.
